# Landing site

Static marketing and hub page for Morpheus AST, live at https://morpheus-ast.vercel.app.

This folder is **not** a third Skeleton Crew app. It does not import `packages/morpheus-ast-core` or either app. The Skeleton Crew apps remain `apps/infrashield-chaos` and `apps/necro-compiler-game`.

## Build

From the repository root:

```bash
pnpm run build:site
```

## Behaviour

- A first-run tour introduces the two demos.
- "Switch world" links move between NECRO-COMPILER and InfraShield 3D.
